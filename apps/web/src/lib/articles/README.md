# Website article modules (published only)

Live Resources articles for zipwiki.ai. **Do not draft here.**

Editorial source of truth: repo-root [`/articles`](../../../../../articles/)
(`{slug}.md` + `{slug}.pdf`).

When publishing, port the markdown into a module here, copy the PDF into
`apps/web/public/articles/`, and add the export to `RESOURCE_ARTICLES` in
`index.ts`.
