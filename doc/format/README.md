# Internal format specs

Public 1.0 docs use **ZipWiki ZIP profile** ([ZIPWIKI_APPNOTE.md](../ZIPWIKI_APPNOTE.md)).

**NeoZip** is the internal parent profile: Extra Field IDs (`0x014E`, `0x014F`),
integrity, and optional sidecars. Keep that wording here; do not lead marketing
or GitHub user docs with “NeoZip.”
